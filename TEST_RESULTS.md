# Результаты проверки

Дата: 11 ноября 2026 года. Python 3.12.3, Flask 3.1.3, Gunicorn 23.0.0.

## Автоматические тесты

`python -m pytest -q` — **15 passed**.

Проверены:

- Главная, страница Guitar Tuner и health-check.
- Кириллица, настроенные ссылки Library/GitHub и внутренняя навигация.
- Отсутствие фиктивных ссылок при пустой конфигурации.
- Состояние без APK и ответ 404 на скачивание отсутствующего файла.
- Содержимое APK, MIME, Content-Disposition, Content-Length, nosniff и Range-запросы.
- Невозможность выбрать другой файл через URL или query-параметры.
- Отклонение небезопасных URL в переменных окружения.
- Доступность локальных ресурсов, кэширование статики, отсутствие cookie.
- Подстановка реальных скриншотов и необязательной даты выпуска через конфигурацию.

## Проверка через Gunicorn

Приложение запущено двумя workers на loopback-порту 8010. Главная, страница тюнера, `/health` и оба локальных WOFF2 вернули HTTP 200.

Скачанный через HTTP APK побайтно совпадает с предоставленным `app-release.apk` по SHA-256. Размер — 8 312 653 байта. Заголовок: `Content-Disposition: attachment; filename=guitar-tuner.apk`.

Из AndroidManifest.xml исходного APK прочитаны: версия 0.1.0, minSdk 26 (Android 8.0). Дата выпуска не задана и не выдумывается.

## Ограничения проверки

Инструмент браузера сообщил `No browser is available`. Визуальная проверка в браузере, измерение горизонтального переполнения и сравнение скриншотов с макетом не выполнены. CSS содержит адаптивные правила для телефонов от 320 px, планшетов и десктопов; это не заменяет проверку в реальном браузере. JavaScript в проекте отсутствует.

Указанные пользователем URL Library и GitHub добавлены в конфигурацию и `.env.example`; проверено их присутствие в ссылках главной страницы. Доступность внешних сайтов не проверялась. Предоставленный `tuner-screenshot.jpg` добавлен в рамку телефона на странице приложения; проверена доступность изображения через Flask.

На VPS ничего не устанавливалось; production-конфигурации существующего сервера не изменялись. Примеры Nginx/systemd подготовлены для ручной адаптации, проверка `nginx -t` на целевом сервере не выполнялась.
